# Cain Barberry – Software Engineering Brand Website

## Overview

My software engineering brand website features a client portal, project highlights, blog, contact form, my resume, and an interactive 3D graphic.

## Features

- **Client Portal** – Access and manage client projects.
- **Project Highlights** – Examples of my past work and accomplishments.
- **Blog** – Articles and insights about software development.
- **Contact Form** – Easily get in touch with me.
- **Resume** – View or download my professional experience.
- **Interactive 3D Graphic** – Engaging, interactive visualization built with modern web technologies.
